# Labor-Productivity-Econometric-Analysis

This project examines the factors influencing labor productivity across 42 European and Central Asian countries, using World Bank data from 2022 and R programming.

The analysis explores the relationship between labor productivity, research and development (R&D) expenditure, internet usage, and tertiary education through simple and multiple linear regression models. It includes hypothesis testing, model validation, residual diagnostics, and statistical tests such as Breusch-Pagan, Durbin-Watson, Jarque-Bera, and Shapiro-Wilk.

Additionally, log-log regression models, outlier treatment, and prediction intervals are used to improve model reliability and estimate productivity levels.

Technologies: R, Econometrics, Regression Analysis, Statistical Modeling.

Data Source: World Bank.
